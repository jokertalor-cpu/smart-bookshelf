အသုံးပြုပုံ လမ်းညွှန်

Smart Bookshelf ၏ လုပ်ဆောင်ချက်များကို အကောင်းဆုံး အသုံးချနိုင်ရန် ဤလမ်းညွှန်ကို ဖတ်ရှုပါ။

နောက်ဆုံးပြင်ဆင်သည့်ရက် — မေ ၂၀၂၆

နောက်သို့ပြန်သွားမည်

၁။ စတင်အသုံးပြုနည်း

Smart Bookshelf ကို အသုံးပြုရန် အောက်ပါ အဆင့်များ လိုက်နာပါ —

၁

Website သို့ ဝင်ရောက်ပါ

၂

Sign Up နှင့် အကောင့်ဖွင့်ပါ

၃

Email Confirmation နှိပ်ပါ

၄

Sign In ဝင်ပြီး စာဖတ်ပါ

Google အကောင့်ရှိပါက Google နှင့် ဝင်ရောက်မည် ကို နှိပ်ရုံဖြင့် Email Confirmation မလိုဘဲ ချက်ချင်း ဝင်ရောက်နိုင်သည်။

၂။ စာအုပ်ရှာဖွေနည်း

Search Bar အပေါ်ဆုံးရှိ Search Bar တွင် စာအုပ်အမည် ရိုက်ထည့်ပါ။ စာ ၂ လုံးမှ စတင်ပြီး အကြံပြုချက်များ ပေါ်လာမည်ဖြစ်သည်။
အမျိုးအစားများ (Categories) Menu မှ "စာအုပ်အမျိုးအစားများ" ကို နှိပ်ပါ။ Novel, History, Knowledge, Technical, Poem စသည့် အမျိုးအစားများဖြင့် ရှာဖွေနိုင်သည်။
လူကြိုက်အများဆုံး / နောက်ဆုံးထွက် Home Page တွင် လူကြိုက်အများဆုံး၊ Download အများဆုံး နှင့် နောက်ဆုံးတင်ထားသော စာအုပ်များကို တွေ့နိုင်သည်။

၃။ စာအုပ်ဖတ်ရှုနည်း

Online ဖတ်ရှုခြင်း စာအုပ်ကို နှိပ်ပြီး Detail Page သို့ ရောက်သောအခါ "ဖတ်မည်" ခလုတ်ကို နှိပ်ပါ။ PDF Viewer တွင် တိုက်ရိုက်ဖတ်နိုင်သည်။
Download လုပ်ခြင်း "ဒေါင်းလုတ်" ခလုတ်ကို နှိပ်ပါ။ ဒေါင်းလုတ်လုပ်ထားသောစာအုပ်များကို Offline တွင်လည်း ဖတ်ရှုနိုင်သည်။
Like နှင့် Library သိမ်းဆည်းခြင်း ကြိုက်နှစ်သက်သော စာအုပ်များကို ❤️ နှိပ်ပြီး Like လုပ်နိုင်သည်။ Library ထဲ သိမ်းဆည်းထားလျှင် LIBRARY Menu မှ ပြန်ဖတ်နိုင်သည်။
PDF Viewer တွင် နောက်ဆုံးဖတ်သောစာမျက်နှာကို အလိုအလျောက် မှတ်မိပေးသောကြောင့် နောက်တစ်ကြိမ်ဖတ်သည့်အခါ ဆက်ဖတ်နိုင်သည်။

၄။ ကိုယ်ပိုင်စာအုပ်စင် (Library)

Library ထဲ သိမ်းဆည်းနည်း စာအုပ် Detail Page တွင် "Library ထဲသိမ်းမည်" ခလုတ်ကို နှိပ်ပါ။ Login ဝင်ထားမှသာ သိမ်းဆည်းနိုင်သည်။
Offline ဖတ်ရှုခြင်း Download လုပ်ထားသောစာအုပ်များကို Internet မရှိသောအခါတွင်လည်း Library မှတစ်ဆင့် ဆက်ဖတ်နိုင်သည်။
ဖတ်ရှုမှုတိုးတက်မှု ကြည့်ရှုခြင်း Library တွင် စာအုပ်တစ်အုပ်ချင်းစီ၏ ဖတ်ရှုမှု Progress ကို ကြည့်ရှုနိုင်သည်။

၅။ AI Assistant အသုံးပြုနည်း

မျက်နှာပြင် ညာဘက်အောက်ထောင့်တွင် ရှိသော 🤖 Robot Icon ကို နှိပ်ပါ —

စာအုပ်အကြံပြုချက် "လူကြိုက်အများဆုံး စာအုပ်ဘာတွေလဲ" သို့မဟုတ် "နောက်ဆုံးထွက် စာအုပ်တွေပြောပြပါ" ဟု မေးနိုင်သည်။
ကိုယ်ပိုင်အကြံပြုချက် AI သည် သင်ဖတ်ရှုမှုမှတ်တမ်းအပေါ် အခြေခံပြီး သင့်နှင့် ကိုက်ညီသော စာအုပ်များကို အကြံပြုနိုင်သည်။
AI ကို မြန်မာဘာသာဖြင့် မေးမြန်းနိုင်သည်။ Rate limit ကြောင့် မက်ဆေ့ ၂ ခုကြားတွင် ၈ စက္ကန့်ခန့် စောင့်ရမည်ဖြစ်သည်။
🌐
SmartBookshelf AI Browser Extension v2.1 တပ်ဆင်နည်း
HTTP/HTTPS website များတွင် AI floating bubble အလိုအလျောက်ပေါ်မည်
1
Account Settings မှ Extension ဒေါင်းပါ
Account page → AI Assistant Settings → ZIP ဒေါင်းလုဒ် button နှိပ်ပြီး ZIP ဖြည်ပါ။
2
Browser Extensions Page ဖွင့်ပါ
Chrome: chrome://extensions  |  Edge: edge://extensions
ညာဘက်အပေါ် Developer mode toggle ဖွင့်ပြီး Load unpacked နှိပ်ကာ folder ရွေးပါ။
3
Extension မှ Sign in ဝင်ပါ
Toolbar မှာ 🤖 icon နှိပ်ပြီး SmartBookshelf ဖြင့် Sign in ဝင်မည် ကို နှိပ်ပါ။ Website login ပြီးလျှင် extension သို့ အလိုအလျောက်ပြန်လာပါမည်။ Token ကူးရန် မလိုပါ။
4
Website များတွင် AI ကို အသုံးပြုပါ
Sign in ပြီးသည်နှင့် HTTP/HTTPS website များတွင် bubble အလိုအလျောက်ပေါ်ပါမည်။ Bubble ကို ဖိဆွဲ၍ screen အတွင်း မည်သည့်နေရာသို့မဆို ရွှေ့နိုင်ပါသည်။ Bubble နှိပ် → မေးခွန်းရိုက် → Enter နှိပ်ပါ။ Camera ခလုတ်ကို နှိပ်သောအခါ chatbox နှင့် bubble ကို ယာယီဖျောက်ပြီး screen ရှင်းရှင်းလင်းလင်း screenshot ရိုက်ကာ ရိုက်ပြီးနောက် အလိုအလျောက်ပြန်ပေါ်ပါမည်။
Session သက်တမ်းကုန်ပါက popup မှ Sign in ကို ပြန်နှိပ်ပါ။ Extension သည် Gemini API key ကို မသိမ်းဘဲ secure proxy မှတစ်ဆင့်သာ အသုံးပြုပါသည်။ Chrome internal pages နှင့် browser store pages များတွင် browser security ကြောင့် bubble မပေါ်နိုင်ပါ။

၆။ အကောင့်ဆိုင်ရာ

Password မေ့သွားလျှင် Login Page တွင် "စကားဝှက်မေ့သွားသလား?" ကို နှိပ်ပါ။ Magic Link, OTP Code သို့မဟုတ် Reset Link ဖြင့် ပြန်လည်ဝင်ရောက်နိုင်သည်။
Google Login Google အကောင့်ဖြင့် Login ဝင်ပါက Password မလိုဘဲ ဝင်ရောက်နိုင်သည်။ Email Confirmation လည်း မလိုပါ။
အကောင့်လုံခြုံရေး Password ၅ ကြိမ် မှားယွင်းပါက ယာယီ ပိတ်ဆို့မည်ဖြစ်သည်။ Password အနည်းဆုံး ၈ လုံး သတ်မှတ်ပါ။

၇။ မေးလေ့ရှိသောမေးခွန်းများ

  • Q: အကောင့်မဖွင့်ဘဲ စာအုပ်ဖတ်လို့ရလား?
    A: အချို့ feature များ (Library, Download) အတွက် Login လိုအပ်သည်။ Browse လုပ်ရန်မူ Login မလိုပါ။
  • Q: Download လုပ်ထားသောစာအုပ်တွေ ဘယ်မှာကြည့်ရလဲ?
    A: LIBRARY Menu → Downloaded tab တွင် ကြည့်နိုင်သည်။
  • Q: AI Assistant ကို ဘာသာစကားဘယ်မျိုးနဲ့ မေးရလဲ?
    A: မြန်မာဘာသာ သို့မဟုတ် အင်္ဂလိပ်ဘာသာ နှစ်မျိုးလုံး မေးနိုင်သည်။
  • Q: Search Bar မှာ စာအုပ်ရှာမတွေ့ရင်?
    A: အမည်တိုတိုဖြင့် ထပ်ကြိုးစားပါ သို့မဟုတ် Categories မှ ရှာဖွေပါ။

နောက်ထပ် မေးမြန်းလိုသောအချက်များ ရှိပါက ကျွန်ုပ်တို့ထံ ဆက်သွယ်နိုင်ပါသည်။
