ကိုယ်ရေးအချက်အလက်မူဝါဒ

Smart Bookshelf သည် သင့်ကိုယ်ရေးအချက်အလက်များကို မည်သို့ ကာကွယ်ထိန်းသိမ်းသည်ကို ဤနေရာတွင် ရှင်းလင်းဖော်ပြပါသည်။

နောက်ဆုံးပြင်ဆင်သည့်ရက် — ဧပြီ ၂၃၊ ၂၀၂၆

နောက်သို့ပြန်သွားမည်

၁။ ကျွန်ုပ်တို့ စုဆောင်းသော အချက်အလက်များ

သင် ဝန်ဆောင်မှုကို အသုံးပြုသည့်အခါ အောက်ပါ အချက်အလက်များကို စုဆောင်းနိုင်ပါသည် —

  • အကောင့်ဖွင့်ရာတွင် အသုံးပြုသော အီးမေးလ်လိပ်စာ
  • Google Login အသုံးပြုပါက သင်၏ အမည်နှင့် ပရိုဖိုင်ပုံ
  • စနစ်အတွင်း သင် သိမ်းဆည်းထားသော စာအုပ်များနှင့် ဖတ်ရှုမှုမှတ်တမ်းများ
  • Website ကို ဝင်ရောက်သည့် browser အမျိုးအစားနှင့် ကိရိယာအချက်အလက် (anonymous)

၂။ အချက်အလက်များကို အသုံးပြုပုံ

  • ဝန်ဆောင်မှုကို ကောင်းမွန်စွာ ပေးဆောင်နိုင်ရန်
  • AI Assistant မှ ကိုယ်ပိုင်စာအုပ်အကြံပြုချက်များ ပေးနိုင်ရန်
  • အကောင့်လုံခြုံရေးနှင့် မမှန်မကန်အသုံးပြုမှုများကို တားဆီးရန်
  • Website လုပ်ဆောင်ချက်များကို ပိုမိုကောင်းမွန်စေရန် ခွဲခြမ်းစိတ်ဖြာရန်

၃။ အချက်အလက် မျှဝေခြင်း

သင်၏ ကိုယ်ရေးကိုယ်တာ အချက်အလက်များကို တတိယပုဂ္ဂိုလ်များထံ ရောင်းချခြင်း သို့မဟုတ် မျှဝေခြင်း လုံးဝ ပြုလုပ်မည် မဟုတ်ပါ။

ကျွန်ုပ်တို့ အသုံးပြုသော ဝန်ဆောင်မှုများ —

  • Supabase — database သိမ်းဆည်းရန် (လုံခြုံသော cloud database)
  • Google Gemini AI — AI Assistant အတွက် (မေးခွန်းသာ ပေးပို့ပါသည်)
  • Cloudflare Workers — API proxy အတွက်

၄။ အချက်အလက် ကာကွယ်ရေး

  • Supabase RLS (Row Level Security) ဖြင့် သင်၏ data ကို သင်သာ ဝင်ရောက်နိုင်အောင် ကာကွယ်ထားပါသည်
  • HTTPS encryption ဖြင့် data များကို လုံခြုံစွာ ပေးပို့ပါသည်
  • Password များကို hash လုပ်ပြီး သိမ်းဆည်းပါသည် (plain text မဟုတ်ပါ)
  • IndexedDB တွင် သိမ်းသော data သည် သင့် device တွင်သာ ရှိပြီး ကျွန်ုပ်တို့ ဝင်ရောက်၍ မရပါ

၅။ သင်၏ အခွင့်အရေးများ

  • သင့် data ကို ကြည့်ရှုခွင့်နှင့် ဒေါင်းလုပ်ခွင့်
  • သင့် account နှင့် data များကို ဖျက်သိမ်းခွင့်
  • ကိုယ်ရေးအချက်အလက် ပြင်ဆင်ခွင့်
  • ဤ Policy နှင့် ပတ်သက်၍ မေးမြန်းပိုင်ခွင့်

၆။ Policy ပြောင်းလဲမှုများ

ကျွန်ုပ်တို့သည် ဤ Privacy Policy ကို လိုအပ်သည့်အခါ အပ်ဒိတ်လုပ်နိုင်ပါသည်။ မည်သည့် အပြောင်းအလဲမဆို ဤစာမျက်နှာတွင် ထုတ်ဖော်ကြေညာမည်ဖြစ်ပြီး "နောက်ဆုံးပြင်ဆင်သည့်ရက်" ကို အပ်ဒိတ်လုပ်မည်ဖြစ်ပါသည်။

သင်၏ ကိုယ်ရေးအချက်အလက်နှင့် ပတ်သက်၍ မေးမြန်းလိုပါက ကျွန်ုပ်တို့ထံ ဆက်သွယ်နိုင်ပါသည်။
